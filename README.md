# Fire Detection Project

This project contains various models and tools for an AI-Based Forest Fire Detection System.

## Contents
- **fire project**: Core project files.
- **Integrated_Fire_System**: System integration files.
- **model 2** & **model 3**: Machine learning models for fire detection.
- **testing**: Testing scripts and data.

## Getting Started

### 1. Activate Virtual Environment
On Windows (PowerShell):
```powershell
.\.venv\Scripts\Activate.ps1
```
On Windows (Command Prompt):
```cmd
.\.venv\Scripts\activate.bat
```
On Linux / macOS:
```bash
source .venv/bin/activate
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Integrated System
You can start the application with a single command from the project root:
```bash
python run.py
```
Or directly with Streamlit:
```bash
streamlit run Integrated_Fire_System/app.py
```
